# CveToad vulnerability management source inventory

## CveToad vulnerability management source inventory

A consolidated super-set source inventory for vulnerability management.

Use it to assess:

* impact
* exploitability
* affectedness
* prioritization
* remediation

{% hint style="info" %}
Treat this inventory as a high-coverage baseline.

Vendor pages change over time.

Always recheck access terms, API limits, and redistribution rights before production ingestion.
{% endhint %}

### Start here

* Read the [canonical inventory](vuln-data-sources.md) for the full single-file reference.
* Use [Intro](cvetoad-vulnerability-management-source-inventory/intro/) for section-by-section navigation.
* Use [Source material](cvetoad-vulnerability-management-source-inventory/source.md) for archived conversion artifacts.

A consolidated vulnerability-management source inventory for assessing impact, severity, exploitability, exposure, affectedness, prioritization, and remediation across technical systems.

### How to use this inventory

* Start with the source class that matches your workflow.
* Use vendor and distribution sources to confirm affectedness.
* Use exploitability and prioritization sources to rank response.

{% hint style="info" %}
Vendor and security URLs change over time.

Access and cost labels are best-effort.

The original monolithic source remains available for auditability.
{% endhint %}
